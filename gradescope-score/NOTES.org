* gradescope-score: upload numeric scores to Gradescope
** usage
: gradescope-score scores.csv
The CSV file must have the following columns in any order
- Score :: numeric score for the "Submission Specific Adjustments"
  field
- Course ID :: course identifier, find in the URL for the course
- Question ID :: question identifier, find in the URL of of a grading
  link
- Zero Rubric ID :: rubric identifier for zero score submissions,
  find in the export of evaluations
- Question Submission ID :: identifier for studnet answer to question;
  distinct from the submission ID

The easiest way to set this up is:
1. Generate the Scores through whatever external means is desired,
   store in a plain text column ordered according to submission number
3. Open one submission and add a rubric item that is designated as the
   0 score item (needed as if no rubric items are marked and a 0
   adjustment score is given, then the submission is ungraded). Open
   the Web Browser Dev Tools, then check the item to generate traffic;
   copy the CURL version of this to the rubric ID (or inspect it)
2. Navigate to the "Review Grades" section on Gradescope for the
   assignmnet
3. From the lower portion select "Export Evaluations" to get a zip of
   all evals
4. Unzip this which will create a directory with a CSV for each of the
   Questions for the assignment and *importantly has Question
   Submission IDs* for all student answers; this spreadsheet already
   has a ~Score~ column 
5. On Gradescope navigate to one student's question and obtain the
   ~Course ID~ and ~Question ID~ from the URL
6. Paste the ~Course ID, Question ID, Zero Rubric ID, and Score~ into
   the CSV / spreadsheet, save as a CSV
7. Run ~gradescope-score~ on that spreadsheet which will update all
   assignments with the scores

* Dealing with Zero Scores

  marked as ungraded
- Need to add in a zero rubric item on Gradescope then check that for
  zero scores
- Added in some code to do this, a minor annoyance but not much way
  around it
- Need to use the DevTools to see the network traffic for the ID of
  the rubric item; possible that might be able to see it in the HTML
  of a loaded page as well but copying the curl output for checking
  the item gives everything needed
- In a future release, consider trying to discover a 0 rubric item in
  the existing rubric
